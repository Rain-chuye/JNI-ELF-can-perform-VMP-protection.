# VMP Shield Pro (Universal Edition)

VMP Shield Pro 现已全面升级，支持 **ARM32 / ARM64** 架构，并解决了文件体积过大及跨架构加密的问题。

## 核心特性 (V12)

1.  **双架构支持**: 完美加固 ARM (32位) 和 ARM64 (64位) 的 `.so` 及 ELF 可执行文件。
2.  **极小体积开销**: 采用 **EOF Payload Injection** 技术，不再预留巨大的缓冲区。生成的加固文件体积仅比原始文件大几百 KB（引导外壳的大小）。
3.  **跨架构加固**: 修复了在 64 位手机上无法加固 32 位文件的 Bug。系统现在可以根据目标文件自动匹配对应的引导存根。
4.  **无 Root 加载**: 继续保留高效的内存链接器，确保在无 Root 环境下正常运行。
5.  **可视化控制台**: 实时显示架构检测（ARM32/64）及封包进度。

## 使用指南

1.  在 AIDE/Android Studio 中构建项目。
2.  选择目标 `.so` 或 ELF 文件。
3.  点击 **INITIATE PROTECTION**。
4.  系统将自动分析架构并生成经过 VMP 处理的加固包。
