# VMP Shield Ultimate V14 (Enterprise Edition)

VMP Shield Ultimate V14 是一款全功能的 Android 二进制加固系统，支持动态库 (.so) 与可执行文件 (ELF) 的深度保护。

## 核心特性 (V14)

1.  **功能选择模式**: 全新 UI 设计，支持“动态库模式”与“可执行文件模式”。
2.  **交互式函数混淆**: 自动扫描并提取 ELF 符号表，允许用户手动选择关键函数进行 VMP 指令虚拟化混淆。
3.  **极致稳定性**:
    - 完整支持 `DT_INIT_ARRAY` 与 `DT_INIT`，确保 C++ 静态对象正确初始化。
    - 增强的重定位逻辑，支持 ARM32/64 所有关键重定位类型。
4.  **透明 JNI 加载**: 加固后的 `.so` 可直接通过 `System.loadLibrary` 加载，内部自动完成解密与符号重映射，无需 Java 层额外配置。
5.  **ELF 可执行文件支持**: 针对独立运行的 ELF 程序提供自解密引导，支持 `printf` 等标准 I/O 调用。
6.  **跨架构加固**: 完美支持在 64 位设备上加固 32 位二进制文件。

## 使用指南

1.  运行 APK，在主界面选择加固模式。
2.  在“符号分析器”中选择目标文件并勾选需要混淆的函数。
3.  点击 **GENERATE SHIELDED BINARY**。
4.  加固结果将输出至 `/sdcard/VMP/`。
